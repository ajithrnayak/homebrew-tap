# ajithrnayak/homebrew-tap

Homebrew formulae for my open-source tools.

```sh
brew install ajithrnayak/tap/xpunge
```

Or tap once, then install by name:

```sh
brew tap ajithrnayak/tap
brew install xpunge
```

| Formula | What it does |
|---|---|
| [xpunge](https://github.com/ajithrnayak/xpunge) | See how much disk space Xcode uses, and reclaim it safely. |
